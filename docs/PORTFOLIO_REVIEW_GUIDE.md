# Portfolio Review Guide

This guide helps recruiters and hiring managers review the proof system quickly.

## 30-second read

The portfolio is built around one public proof hub and several supporting prototypes. The featured project is AXE-LAB v4, a deterministic LLM evaluation harness that demonstrates AI workflow evaluation, prompt-system comparison, output validation, rubric scoring, failure tagging, report generation, and careful claim control.

## How to interpret the work

The projects are intentionally scoped as proof-of-work prototypes. They should be evaluated for workflow thinking, system design, documentation quality, implementation discipline, and ability to turn ambiguous ideas into structured systems.

## What not to infer

Do not infer:

- senior production ML engineering experience
- commercial production user base
- enterprise deployment readiness
- live commercial LLM benchmark results
- completed platform certifications unless listed separately

## Best interview prompt

Ask the candidate to walk through:

1. How AXE-LAB validates and scores model outputs.
2. Why deterministic stand-ins were used.
3. How the same evaluation pattern could apply to CRM follow-up drafts or marketing automation outputs.
4. How yard0s maps to field-service implementation workflows.
5. What would be added next to move from proof-of-work to production.
