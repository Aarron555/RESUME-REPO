# Dumbwork Dumb Scan
Systems for boring work diagnostic and routing engine.

## Local run
- `npm run qa`

## What it does
- Scores scans, detects red flags, routes to one First Fix recommendation, blocks unsafe deposits, and sets next best action.

## Admin access
- Admin UI routes are placeholders and require auth implementation before production.

## Demo data
- File storage at `data/db.json`.

## Known limitations
- No production auth yet.
- Payment/booking automation is manual for private beta.
